# Baqalat Sheemah Khulaif Aayed Al-Enazi Lil-Mawad Al-Ghidha'iyyah POS

A professional Point of Sale system for Baqalat Sheemah Khulaif Aayed Al-Enazi Lil-Mawad Al-Ghidha'iyyah (بقالة شيمه خليف عايد العنزي للمواد الغذائية), built with React.

## Getting Started

This project includes a complete POS application with features for sales management, inventory, and reporting.

## Development

Run `npm run dev` to start the development server.

Run `npm run build` to build for production.
